## Agent posture (Claude / Codex / Grok)

When working on OSS GitHub for Dasha:

1. Prefer **welcoming, concise** copy. Invite ideas over forbidding lists.
2. **Community input decides what to build** — infra, consumer, creative, anything cool and useful.
3. Keep desk **MIT + static-friendly**; new surfaces can be new packages/repos when needed.
4. Ship hygiene (LICENSE, security, build check) without turning CONTRIBUTING into a wall.
5. Do **not** frame the OSS product as thesis/receipts/FOMO tooling.
