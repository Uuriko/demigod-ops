## No-mail anti-impersonation profile

# Current repository and public product expose no @getdasha.com mailbox or mail workflow.
# While that remains true, publish these records together:

Type    Name       Priority    Value
MX      @          0           .
TXT     @                      v=spf1 -all
TXT     _dmarc                 v=DMARC1; p=reject; sp=reject; adkim=s; aspf=s

# Null MX: the domain accepts no mail. SPF: no server may send mail for it.
# DMARC: reject non-aligned apex and subdomain mail. No rua address is invented.
# Before any legitimate @getdasha.com mail is introduced, replace all three as one
# reviewed mail-provider migration and add that provider's DKIM records.
