## Webflow UI steps

1. Site settings → Publishing → Custom domains → Add domain
2. Add apex + www
3. Copy the DNS values Webflow shows into the registrar
4. Wait until Webflow shows domain as connected
5. Set default domain
6. Publish → select custom domains
