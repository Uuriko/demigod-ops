## What Dasha is now

Dasha is a live Solana culture project with six connected surfaces: Home, Meme Studio, Desk, public Lobby, optional X OAuth and an opt-in measured Simp Board. The public product has two jobs:

1. make `$dasha` easy to understand, verify and buy without deceptive claims;
2. give people a fun reason to create, return and bring others into the culture.

The live home at `https://www.getdasha.com/` is the front door. It leads to creation/remixing, the Lobby and Board, the associated mint, Jupiter, market sources and the deeper `/dasha` desk. Transmissions/alibi remains one unproven creative experiment inside this system; it is not the definition of the whole product.

## Current product system

**Dasha Meme Studio** turns one line into an X-ready image and passes the exact editable state to the next person. The **Lobby** provides one moderated public room with optional X linking. The **Simp Board** is a parallel recognition loop: X OAuth alone never enrolls; users explicitly join or leave; PerryALPHA's founding #1 row is disclosed as editorial and non-measured; joined accounts may submit public creative, community and open-source evidence for review.

New remix state lives in the URL fragment, which browsers do not send in the HTTP request; legacy query links still load and normalize client-side. Native sharing carries the PNG and remix URL together; the X fallback saves the PNG and opens a documented Web Intent containing the editable URL. A materially changed inbound artifact keeps exactly one validated immediate parent snapshot and exposes a local `From` link; this is state ancestry, not proof of identity, authorship, permission or endorsement. A maker can prepare the same look and line as explicit post, story and banner downloads. The output carries a small `getdasha.com` mark, but never a price promise or implied endorsement.

The live Board gives fixed, capped points for recognized creative/community work and the existing OSS schema; follower count, verification, reactions, chat volume, referrals, purchases, balances, bag size and payments score zero. It also provides personal score-card PNGs, earned badges and frozen operator-created season snapshots; IDs cannot be overwritten and only the newest 24 are retained. The optional signed holder badge scores zero. Its dated check proves only that the signing wallet held a positive raw amount of the associated mint at finalized commitment; the 28-day display is not continuous-holding proof or Sybil resistance. The flow sends no transaction and stores or publishes no wallet address or balance.

A separate prepared open-source lane can award honor-only Simp Points for merged work in `Uuriko/dasha-desk`. GitHub supplies public authorship, merge and review evidence; one maintainer-applied impact label supplies a fixed 5/15/40/100/200-point award. Operators, bots, direct pushes, self-approved work and unmerged activity score zero. No current PR qualifies, so the public score remains empty rather than backfilled from commits.

Why this is the lead:

- it creates a repeatable activity instead of another static token page;
- every exported artifact can distribute the brand outside the site;
- it works without a wallet and remains useful whether or not the user buys;
- it fits the observed cultural basis of memecoin participation better than invented token utility.

This is still a hypothesis. Distinct non-operator creation, editable handoff, acknowledgement and voluntary return—not feature completion—are the evidence.

## Next discriminating experiment

Test **Transmission 001: make me an alibi.** It is one bounded, seven-day situation with an original, deliberately incomplete Studio starter; one action designed to take minutes; the existing image-plus-editable-link share path; one manually reviewed submission path; acknowledgement by the end of the next calendar day for every distinct person's first valid submission; and one small editorial closing record. Selected responses may influence a second Transmission, but a second episode is not scheduled in advance.

This tests whether Dasha can become a recurring, community-authored character ritual without committing to accounts, a feed, an AI chatbot, automated X scoring, wallet gating, token rewards or governance. Continue only if distinct non-operator participants create materially changed work and at least one returns, remixes or asks for the next prompt. ## Candidate product bets

These are alternatives, not a feature backlog. The current experiment is Transmission 001. Remix Relay is the critical behavior inside it: do recipients preserve and use editability, or keep only the flattened image? Evidence—not enthusiasm—selects any expansion.

| Bet | Core loop | Why it could matter | Main risk |
|---|---|---|---|
| **Remix Relay** | Open exact state → change one thing → pass it on | The existing Studio can test portable cultural mutation immediately | People may keep the PNG and discard editability |
| **Moment Capsules** | Contribute once to a bounded moment → receive a shared zine | Turns a community event into a durable object without identity or NFTs | Empty-room and moderation risk |
| **Portable Culture Kits** | Fork a proven Dasha visual voice for another community | Could make Dasha the renderer for culture outside its own audience | Becomes generic templates without strong art direction |
| **Culture Capsules** | Close one shared crypto moment into a titled, source-linked, multi-person zine → reopen and edit | Gives transient community activity a durable, portable group memory without a feed or wallet | Contributions may remain operator-assembled rather than genuinely collaborative |
| **Transaction Preflight** | Inspect an unsigned request → understand permissions and unknowns → decide elsewhere | Solves a serious crypto trust problem | Full identity pivot with wallet-security competition |

The ambitious horizon is **Open Culture Objects**: a documented, host-independent recipe for a flattened render plus its editable state and bounded parent/source context. The current Studio proves only its own save-and-rehydrate path; it does not become an open format until Relay behavior exists and a second independent consumer passes shared fixtures. See [`DASHA-OPEN-CULTURE-OBJECTS.md`](DASHA-OPEN-CULTURE-OBJECTS.md).

Culture Capsules remain a prepared group-assembly experiment, not the platform direction. Kill them after three distributed capsules if nobody outside the operator contributes or reopens and changes one. Generic interactive memes are not a Dasha wedge: Rezona, Sekai, Variant and Pops already occupy create/play/remix/share.

## Conversion layer

The website may embed Jupiter's official swap plugin with `$dasha` fixed as the output mint. It must retain a direct Jupiter fallback, make the mint visible and keep the high-risk disclosure adjacent. Dasha does not custody wallets, route swaps itself or call any token safe.
