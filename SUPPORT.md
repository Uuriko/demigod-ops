# Support

GitHub is the official support room. There is **no official Discord, Telegram,
Slack, WhatsApp, or other off-site chat**.

| Kind | Where |
|------|--------|
| Bug or unexpected kernel/docs behavior | [Open an issue](https://github.com/Uuriko/demigod-ops/issues/new/choose) |
| Design or “how should this work” | [Discussions](https://github.com/Uuriko/demigod-ops/discussions) |
| Vulnerability, leaked secret, or CoC report | [Private advisory](https://github.com/Uuriko/demigod-ops/security/advisories/new) — see [SECURITY.md](SECURITY.md) |

Search existing issues first. Name the surface in the title (`kernel`, `packet`,
`contracts`, `docs`). Include what you ran and expected vs observed.

Do **not** paste hiring PII, résumés, emails, OAuth tokens, wallet keys, or live
secrets.

A merged PR can sit ahead of live `trydemigod.com`. `bin/dg truth` is website
truth. Live Webflow / CDN publish is not how you get support or land a change.

See [CONTRIBUTING.md](CONTRIBUTING.md) for how to send a PR.
