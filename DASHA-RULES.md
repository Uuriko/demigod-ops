# Dasha agent rules (one card)

Everything agents must follow for getdasha.com. Prefer this over hunting 80 markdown files.

## Product

1. **Active project = Dasha** until the user names another.
2. **Scrapped forever:** Thesis Card, conviction receipts, Pair, forecasting/rounds — do not revive.
3. **Public loop:** Make → Play → Buy. Chess / seasons chrome / dual quiz counts on buttons / Telegram community — frozen or banned as public growth surfaces.
4. **Canonical product truth:** `DASHA-PRODUCT-BRIEF.md` · Studio ambition: `DASHA-CULTURE-STUDIO-PRODUCT.md` · order/gates: `DASHA-ROADMAP.md`.
5. **Claims:** narrowest wording only — `DASHA-CLAIMS.md` (C1–C13). No “safe,” token control, endorsement, or points for buys/likes/referrals.
6. **Threats:** `DASHA-THREAT-MODEL.md` — a failing control blocks the surface; do not weaken the check.

## Ship / truth

7. **SoR for ship-bound files:** `/home/potter`. Worktrees for isolated edits; promote before ship.
8. **Live Studio/lobby clients:** prefer worker-tree deploy path; do not push root shadow Studio over thin live loader.
9. **Publish / outbound / money / posts / forms:** only if the **current** user request authorizes it. Prepare and verify by default.
10. **After Worker client deploy:** recompute SRI and re-pin HTML before Webflow ship (`--only=` preferred).
11. **Verify user-visible embeds** (board SRI, studio thin, desk AA) — green markers alone can lie.
12. **Commands:** `npm run dasha:check` · `dasha:gate` / `dasha:gate:fast` · `node dasha-live-verify.mjs` · `node dasha-ship.mjs --only=<surface> …` with publish auth.

## Multi-agent

13. Bus: `bin/dg-bus` with **`--from` required**. Protocol: `AGENT-COMMS.md`.
14. **One writer per file** — claim before editing shared sources.
15. Interactive sessions do not auto-read the bus; use `send` / `task` / handoff path.

## Code / communication

16. **Ponytail:** YAGNI → reuse → stdlib → native → dep → minimum. Keep security, a11y, validation.
17. **Do not assign the user work.** Report what *you* did or blocked on.
18. **Keep working** inside Dasha while unblocked; stop on auth, true ambiguity, or safety.

## Docs

19. **Read path:** this file → `DASHA-DOCS.md` → Brief / Roadmap / Workflow as needed.
20. **Archive** (`archive/dasha-docs/`) is evidence only, not standing rules.
21. Do not invent new canonical owners without updating `DASHA-DOCS.md` and the docs gate.

## Hard stops (machine)

22. Eat the Sounds game: off-limits unless user reopens.
23. Demigod: paused unless user reopens; do not mix into Dasha sessions.
