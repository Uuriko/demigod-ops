# PIL-01 — Pilot lifecycle

**Owner:** CS / founder · **When:** real search open → close  
**SoR:** `demigod-ops/PILOT-LOG.md` · pilot-logger · white-glove playbook

## Open
- [ ] Real named counterparty (never selftest as pilot)
- [ ] INT-01 accepted brief
- [ ] Capacity: owner can respond personally
- [ ] Terms pointed at fee one-pager
- [ ] Log open in PILOT-LOG

## Run
- [ ] WHITE-GLOVE first 30 min / same-day blocks
- [ ] MAT-01 before each slate
- [ ] INT-03 for each intro
- [ ] Weekly status to founder (facts only)

## Close
- [ ] Outcome: hired / paused / declined / no-fit (honest)
- [ ] Invoice path or explicit waiver
- [ ] Retrospective 5 bullets (what worked)
- [ ] Proof only with consent (PRF via HIR-01)

**Never:** invent pilots to make pipeline look full
