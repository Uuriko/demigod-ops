# INT-01 — Intake / brief acceptance

**Owner:** Talent lead · **When:** form submit, email brief, or warm reply before sourcing

## Capture
- [ ] `bin/dg inbox` reviewed (or hello@ thread logged)
- [ ] Company + contact (minimize PII in agent logs)
- [ ] Role title + location / remote
- [ ] Comp cash/equity (range OK)
- [ ] **90-day outcome** measurable (block if missing — ask once)
- [ ] Must-haves vs nice-to-haves separated
- [ ] Hiring authority + interview owner
- [ ] Fee terms acknowledged: 10% on hire, no SLA (`docs/gtm/FEE-ONE-PAGER.md`)

## Accept / reject
- [ ] Accept only if authority + 90d + lawful criteria clear
- [ ] Reject/spam/duplicate dispositioned with reason
- [ ] **Do not** mint public board role from mere interest

## Record
- [ ] Write `demigod-ops/intake/<brief-id>.md`
- [ ] Optional: pilot logger entry when search truly open
