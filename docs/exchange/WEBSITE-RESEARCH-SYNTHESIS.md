# Website redesign — research synthesis

**Date:** 2026-07-16 · For multi-agent design lab  
**Purpose:** One research pass so agents stop re-googling and start scoring variants.

## 1. B2B SaaS landing pages (2026 patterns)

Industry consensus (DesignRevision and peers):

- **5–8 sections** structured pages convert better than unstructured dumps.  
- **Outcome headline** &gt; product label.  
- **Dual CTA paths** common (trial vs sales; here: hiring vs looking).  
- **Social proof above fold** helps *when real*; Demigod must omit fake logos.  
- **Speed** is conversion (LCP &lt; 2.5s narrative); heavy runtime DOM rewrite hurts.  
- **One goal per page**; nav link farms compete with conversion.

Anatomy to mirror (adapted):

Hero → (optional real trust) → problem/solution → 3 benefits/process → pricing → close dual CTA.

## 2. Recruitment / talent LPs

Career/recruitment LP guides emphasize: clarity of role, speed, trust, single conversion goal.  
Marketplace sites that work visually: clear employer vs talent split, process transparency, fee honesty.

**Demigod translation:** dual path is the product; process is the trust; fee is 10% on hire; no inventory theater.
