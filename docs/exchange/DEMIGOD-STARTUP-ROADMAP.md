## 1. What we are

**Demigod** = human-curated **SF seed / early-stage** talent matching.

| Principle | Meaning |
|-----------|---------|
| Mutual yes | No intro until both sides agree |
| 90-day outcome | Highest-signal brief input (MOC-lite) |
| Private until fit | No blast lists |
| 10% on hire | vs typical 15–25% contingency |
| Honesty | Sample roles labeled; pending Stripe/SMS said plain; no SLA clocks |

**Not:** job board, ATS, recruiter marketplace, AI spam engine.

**One-liner for DMs:**  
*Not a job board or ATS — human-matched SF seed intros, 90-day outcome first, mutual yes only, 10% only on hire.*

## 2. How we make money

| Path | When | Notes |
|------|------|--------|
| **Primary:** 10% first-year cash on hire | From hire #1 | Invoice manually if Stripe pending |
| Credited kickoff deposit | Optional | Applied to success fee |
| Fixed sourcing sprint | If founder won’t sign full search | Shortlist deliverable |
| Hiring diagnostic | Later | Role + scorecard design |
| Partner / VC share | After proof | Share of placement, not listing fees |

**Unit sketch:** $180k eng → **$18k** Demigod vs $27–45k agency.  
**Early goal:** 1 paid placement proves model; 4–6/year is a real solo/concierge business.

### Phase 1 — Demand + first pilot (NOW → 30 days)
**North star:** warm conversations → one white-glove match attempt → honest log.

- [ ] 15+ warm SF founder touches (human sends)
- [ ] Top3 sent + logged
- [ ] Douglas / intros converted to `/?wiz=startup` briefs

- [ ] 30 candidates in niche (eng / founding eng SF)

### Phase 2 — Proof + repeatability (30–90 days)
- [ ] First mutual-yes intro completed
- [ ] First placement fee invoice (or clear near-miss learnings)
- [ ] Proof asset (anonymized process / quote if earned)
- [ ] 3 design-partner searches in pipeline
- [ ] Partner touch: 1–2 VCs/accelerators
- [ ] Stripe when first invoice due

### Phase 3 — Light talent-eng OS (90 days–6 mo)
*Only after demand proves pain.*
- [ ] Matching CRM / pipeline board (real data only)
- [ ] Outcome template library by role
- [ ] Sourcing assist (research tools; human gate on all outreach)
- [ ] Portfolio desk offer for VCs

### Phase 4 — Scale judgment (6–12 mo)
- [ ] Retention narrative from real placements
- [ ] Optional retained tier for repeat founders
- [ ] Team / ops as volume requires
- [ ] Still: systems earn human conversation, never replace it
