## Same problem, different product

Both care about **AI-era builders** and hate empty Easy Apply.

| | Builders | Demigod |
|--|----------|---------|
| Portable technical bar | **Yes** (cert / take-home) | **No** — optional external evidence only |
| Multi-company after one bar | **Yes** (claimed network) | **No** — per-role mutual match |
| Human in the loop | Reviewer debrief + placement team | Match review + mutual yes |
| Geography | Global candidates; mixed partners | **SF / Bay density** |
| Company economics | **10% cash (base+bonus)** first hire → **15%** later ([/refer](https://builders.cv/refer)) | **10% first-year base only**, transparent |
| Candidate cost | Free entry | Free |
| Trust model | Pass the test → skip early screens (varies by partner) | Both sides approve before names move |

---

## When Builders wins

- Candidate wants **one bar → many intros**  
- Company wants **pre-certified** top-of-funnel  
- Role is pure ship-with-agents product eng  

## When Demigod wins

- Founder wants **role + 90-day outcome** fit, not a global leaderboard  
- **Mutual consent** and relationship matter more than speed of multi-blast  
- Honest fee and SF startup map / ops density  
- Candidate has strong work evidence **without** needing another OA  

---

## What Demigod should never do

- Rebuild Builders / Exceptional / CodeSignal / Promptster  
- Promise “skip screens at 20 companies”  
- Treat Builders pass as auto-intro (still human + mutual yes)  

## What Demigod should do

- Accept Builders/Exceptional/work links in **existing** resume + experience fields  
- Match checklist: AI-native ownership questions (`MATCH-QUALITY-CHECKLIST.md`)  
- Stay the **SF mutual-yes placement** product
