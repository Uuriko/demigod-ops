1. Webflow → Apps & integrations → API access → create a site token. Write it to

2. Create `~/.config/demigod/webhook.env`, **chmod 600**, with a **hex** secret of
   32–256 characters. Two traps: a non-hex value is silently rejected, and the file
   is ignored entirely if group or other can read it.
3. A stable public URL for the receiver, then register it —
   `demigod-webflow-webhook-setup.mjs` writes the setup receipt.
