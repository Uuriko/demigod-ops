## 1. What Exceptional Builders is

| Field | Fact |
|-------|------|
| Host | **Pensive** via platform **[Builders](https://builders.cv/)** (builders.cv) |

| Pitch | One AI-native full-stack build → multi-company network intros |

## 6. Parent product: Builders (builders.cv)

**Breakthrough (2026-07-31):** Exceptional is a **campaign surface** on **[Builders](https://builders.cv/)** (Pensive).

| Surface | URL | Role |
|---------|-----|------|
| Marketing campaign | exceptional.builders | “1 assessment · 20 companies” cohort (closes Aug 9) |
| Platform | builders.cv | “Build. Show. Get Hired.” proof-of-work network |
| Take test entry | builders.cv/exceptional/entry | Email + 6-digit code auth |
| Certification | builders.cv/get-certified | Pass once → network unlock |
| B2B | builders.cv/business | “Talent partner to hire exceptional builders” |
| Refer | builders.cv/refer | Refer & earn |
| Contact | hello@builders.cv | — |

**Product loop (builders.cv):**
1. **Submit work** — pull LinkedIn/GitHub/hackathon/founding signals into a profile  
2. **Get certified** — optional AI-native take-home + debrief; “Passing unlocks every company on the network”  
3. **Get hired** — team pitches, fast-tracks, follows through until placed  

**Certification details (get-certified):**
- 60-min full-stack build; timer starts when candidate clicks Start  
- **Auto evaluation** after submit  
- Optional **30-min** reviewer feedback call (pass or fail)  
- Claims: skip résumé + first technical round; pass once for whole network  
- Explicit: companies like **Ramp and Blockit** “don’t take cold applications”  

**Take-test flow:** exceptional.builders CTA → `builders.cv/exceptional/entry` (email OTP). No public partner API.
