## 9. What to actually study on each visit (checklist)

For each site, screenshot or note:

1. **Hero:** H1 length, sub length, CTA count (1 vs 2), trust line  
2. **Nav:** how many links before “more”  
3. **Motion:** scroll vs hover vs page-load (don’t over-animate Demigod)  
4. **Proof:** logos, numbers, quotes — placement density  
5. **Pricing:** one card vs comparison table  
6. **Footer:** link count (anti-bloat lesson)  
7. **Dark vs light:** mood without crushing readability  
8. **Mobile:** sticky CTA bar pattern
