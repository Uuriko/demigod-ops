# Application Packet: Alchemy $20M Solana Fund for Dasha Infrastructure Evaluation

This document outlines the application packet for the Alchemy $20M Solana Fund to support Dasha infrastructure evaluation.

- **Lock-in:** None

2. Benchmark performance, latency, and reliability under load.
