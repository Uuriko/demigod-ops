# White-glove playbook — founder replied / brief inbound

**Trigger:** reply, form submit, or warm intro.  
**Promise language:** no 48h/SLA. Use: *hello@trydemigod.com will follow up.*

## Five P0 risks
1. **Slow response** — interest cools before a personal acknowledgment and next step.
2. **Incomplete brief** — missing 90-day outcome, must-haves, comp, location, or decision-maker → weak matches.
3. **Expectation mismatch** — they assume job board, automation, guaranteed candidates, or fixed turnaround.
4. **No qualified supply** — warm network may not hold a credible fit yet.
5. **Process/commercial ambiguity** — privacy, consent, mutual-intro, interview ownership, 10%-on-hire not confirmed.

## First 30 minutes
1. [ ] Thank them (human, short) — no timing or volume promises
2. [ ] Confirm role + **measurable 90-day outcome** (if missing, ask once)
3. [ ] Capture: title, comp/equity, location, employment type, start window
4. [ ] Separate must-haves vs preferences; note deal-breakers
5. [ ] Confirm hiring authority, interview stages, feedback owner
6. [ ] Log: company, role, stack, source — **do not** mint board roles from mere interest
7. [ ] Restate: human-reviewed, private until mutual yes, 10% on hire only

## First work block (same day if possible — no public clock)
8. [ ] Written scorecard + search thesis
9. [ ] Warm network first (5–15 leads); narrow personalized outreach only after
10. [ ] Score vs 90-day outcome (capability / motivation / stage fit)
11. [ ] Shortlist **2–3** max with written *why* + open questions
12. [ ] Ask founder: “send these 2–3?” before naming the company to candidates

## Mutual yes
13. [ ] Candidate consent before sharing profile details with founder
14. [ ] Founder yes on shortlist
15. [ ] Intro email (both sides): context + 90-day outcome + next step
16. [ ] Log intro honestly — not fake receipts

## After intro
17. [ ] Soft check-in (no SLA): “any useful?”
18. [ ] Hire path: fee 10% terms + invoice when start date real
19. [ ] Proof asset only with consent (anonymous OK)

## Never
- Blast resumes · invent candidates · promise speed · auto-board mint · concurrent foot edits mid-pilot · invent urgency/volume
